## 1. Story Goal

D6 pulled `t50_lanes` into wave 1b so the penguin lane game can migrate with every other room. It cannot
exist without Steer (lanes) and Spawner, so both arrive here — which also repairs the original order, where
wave-2 `t38_peekaboo` needed a modifier scheduled for wave 3.

## 2. Requirements

#### ADDED: Steer, free and lanes
**After:** `free` follows the finger inside a bounded area; `lanes` snaps to the nearest of n lanes on release, never mid-drag. The lane count comes from the def.

#### ADDED: Spawner as a shared modifier
**After:** Emits objects on a declared cadence from a declared set, with a lifetime and a despawn rule, deterministic from a seed so a replay is exact. Usable by `t37`, `t38`, `t41` and `t46` later — `t50` is one consumer, not the owner.

#### ADDED: t50_lanes
**After:** Objects are caught, never shot: no projectile, no lives, no screen shake, nothing to crash into. A missed object leaves quietly.

#### REMOVED: Shooting and losing
**Before:** TutoTOONS' `Template50Player` has `ShootBullet`, `MoveToClosestLine` and scene restart on failure.
**After:** (removed) — a four-year-old care game has nothing to shoot and no fail state; the motion and the lane logic are kept, the weapon and the loss are not.

## 3. Acceptance Criteria

1. **Strict Typing & Lint:** fully annotated; lint/format pass; bars hold.
2. **Steer modes:** `free` (follow the finger in a bounded area) and `lanes` (snap to the nearest of n lanes on release, with the lane count from the def).
3. **Spawner as a modifier:** emits objects on a declared cadence with a declared set, a lifetime and a despawn rule; deterministic from a seed so a test can replay it exactly.
4. **`t50_lanes` collects, never shoots:** the TutoTOONS template has `ShootBullet`; this one has no projectile and nothing to hit — objects are caught. Losing is impossible: a missed object leaves quietly.
5. **No lives, no screen shake:** `DecreaseLife`/`ShakeScreen` have no counterpart and no def value can switch them on.
6. **Determinism:** the same seed and the same touch stream produce the same objects in the same lanes.

## 4. Zoom-Out on the Modules This Touches

**`Spawner (new, shared)`** — purpose: produce timed objects for any template that needs them.

- Callers: `t50` now; `t37`, `t38`, `t41`, `t46` in later waves.
- Contracts to preserve: Seeded determinism, no network, no wall clock; a spawner that stops must leave no orphans (the monkey fuzz counts them).

## 5. Frozen Contracts

### Spawner is shared, not owned

The modifier is usable by `t37`, `t38`, `t41` and `t46` later; `t50` is one consumer, not the owner.

### Steer reports position, the template decides meaning

The primitive moves and snaps; whether a lane collects or reveals is the template's business.

### A miss is quiet

No penalty, no life, no sound that reads as failure.

## 6. Implementation Steps

1. Write the failing tests: lane snapping on release only, seeded spawner determinism, catch scores and miss does not → `verify:` `test -f game/tests/unit/test_steer_primitive.gd`
2. Implement the Steer primitive (free + lanes) and the Spawner modifier with a seed → `verify:` `gdlint game/ && gdformat --check game/ && godot --headless --path game -s tools/type_gate.gd`
3. Implement `t50_lanes` with catching and no loss, consuming both → `verify:` `godot --headless --path game -s addons/gut/gut_cmdln.gd -gexit -gselect=test_t50_lanes`
4. Author a lane def and prove seed-determinism plus zero orphans across a long run → `verify:` `godot --headless --path game -s addons/gut/gut_cmdln.gd -gexit -gselect=test_spawner`

## 8. Out of Scope

- `t26_ride`, `t37` and `t41` consumption of Spawner (wave 3).
- Any shooting, racing or scoring-against-a-clock behaviour.

## 9. Risks

- **Orphan nodes from spawned objects** — the repo already counts them. Mitigation: the despawn rule is asserted by the orphan counter in the standard GUT run.
- **A lane snap mid-drag** feels broken. Mitigation: the test asserts no snap until the finger lifts.
- **Spawner becoming `t50`-shaped** would force a rewrite for `t37`/`t41`. Mitigation: the modifier takes a def-owned spawn table, and a second consumer is written in the test as a stub.

3. Objects arrive; catch one → it scores; miss one → nothing bad happens.
4. Relaunch with the same seed → the same objects arrive in the same lanes.
