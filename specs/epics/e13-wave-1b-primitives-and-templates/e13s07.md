## 1. Story Goal

Build the two guessed templates to the rule e13s06 produced, or record the skip and restate the coverage.
`t22_play_beat` is the tableau where objects answer a touch with animation and sound; `t3_skip_beat` is the
short beat a child can skip.

## 2. Requirements

#### ADDED: t22_play_beat
**After:** Every object answers its own touch with its own reaction, no order is required, and the step ends on counted touches — never when the sounds finish (`CheckIfSoundsEnded` maps to a progress check).

#### ADDED: t3_skip_beat
**After:** Any input skips the beat, and skipping never loses a reward the def declares.

#### MODIFIED: The rule these two templates implement
**Before:** The rule was the template table's guess, with no confidence level and no evidence beyond method names.
**After:** The rule is `TEMPLATE_EVIDENCE_T22_T3.md`. Where the evidence is silent, the def carries a parameter with a default, so a wrong guess is a data change rather than a code change.

## 3. Acceptance Criteria

1. **Strict Typing & Lint:** fully annotated; lint/format pass; bars hold.
2. **The evidence document is the specification:** the implementation matches `TEMPLATE_EVIDENCE_T22_T3.md` section by section; any divergence is fixed in the document first.
3. **Every object answers:** `t22` gives every object its own reaction and requires no order; it ends when the child has touched what the def counts, never when the sounds finish (`CheckIfSoundsEnded` maps to a progress check, not a step end).
4. **`t3` skips on any tap:** a beat is skippable by any input, and skipping never loses a reward the def declares.
5. **A skipped template is recorded, not silently dropped:** if e13s06 said skip, this story's acceptance is the corrected coverage claim plus a row in the template table saying why it is not built.

## 5. Frozen Contracts

### No invented behaviour

Where the evidence is silent, the def carries the decision as a parameter with a default, so a wrong guess is a data change, not a code change.

### Sounds are reactions, not a clock

Nothing in either template schedules the end of a step from an audio duration.

## 6. Implementation Steps

1. Write the failing tests from the evidence document, one per claim → `verify:` `test -f game/tests/unit/test_t22_play_beat.gd`
