## 1. Story Goal

The last wave-1 template, and the gate that closes the wave: thirteen templates with a written rule, a
unit test and a scene, and a coverage number that is measured rather than claimed.

## 2. Requirements

#### ADDED: t51_prize_pick
**After:** A set of prizes from the def, one tap to pick, the pick saved through `ProgressManager`. `AddVideoAdReward` has no counterpart: no ad, no second pick.

#### ADDED: The wave-1 completeness gate
**After:** `specs/product/TEMPLATE_TABLE.md` lists all thirteen wave-1 templates with rule, def parameters and evidence source; a test fails if any of them lacks a rule, a unit test or a consuming scene, or if the coverage claim disagrees with the table.

#### MODIFIED: How the wave's coverage is stated
**Before:** The scope claims 88.4% of 1,801 template scenes from a build-order table that no test reads.
**After:** The claim is computed from the template table by a test, so a skipped template forces the number down in the same commit instead of leaving prose that overstates.

## 3. Acceptance Criteria

1. **Strict Typing & Lint:** fully annotated; lint/format pass; bars hold.
2. **`t51_prize_pick`:** a set of prizes from the def, one tap to pick, the pick saved through `ProgressManager`. The TutoTOONS template's `AddVideoAdReward` has no counterpart: no ad, no second pick.
3. **Thirteen rules written:** `specs/product/TEMPLATE_TABLE.md` lists all thirteen wave-1 templates with their adaptation rule, their def parameters and their evidence source.
4. **Coverage is computed, not asserted in prose:** a test reads the table and the template registry and fails if a wave-1 template lacks a rule, a test or a scene, or if the coverage claim in the scope disagrees with the table.
5. **The wave is honest:** if any template was skipped by e13s06/e13s07, the scope's percentage is the number the table supports, and the difference is named.

## 5. Frozen Contracts

### A template without a scene is not done

The completeness gate requires a scene that uses it; a library entry with no consumer is unverified weight.

### Prizes are data

The prize set, the odds and the once-only rule are def and service values; the template has no table of its own.

## 6. Implementation Steps

1. Write the failing prize tests and the completeness gate over the template table → `verify:` `test -f game/tests/unit/test_template_registry.gd`

## 9. Risks

- **A registry test that passes vacuously** because it reads the same file it validates. Mitigation: it reads the template *scripts* on disk and the table, and fails when either is missing a row.
- **A second pick or an ad branch** reappearing from the TutoTOONS template. Mitigation: a source-scan assertion over the template file.
- **The number drifting from the table** on the next edit. Mitigation: the number is derived, not typed.
