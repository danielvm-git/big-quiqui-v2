# e06s01: Interactive Garden Props: Bouncing Ball, Hug Plushie, Spinning Pinwheel & Tickle Zone

<!-- story: e06s01 -->
- **Epic:** `e06-garden-play-scene`
- **BCP:** 4
- **Playable Vertical Target:** `res://scenes/jardim.tscn`
- **Threat findings closed here:** T-E06-03, T-E06-04

## 1. Story Goal
The garden is play, not a task: three toys and a tickle zone, each with a bounded motion, and the step
completes when the child has played with three **distinct** toys. The same toy four times is still fun and
still does not finish the step.

## 2. Acceptance Criteria
1. **Strict Typing & Lint:** `gdlint game/ && gdformat --check game/` exits `0`, type gate passes.
2. **Explicit State Machine:** the room machine is `PLAYING -> FINISHED`; the loop is driven only through
   `CareLoopManager`, with a clean `FsmProbe` in the E2E.
3. **Touch & Mouse-Echo Safety:** props ignore `device == -1`; one tap is one interaction under `TouchSim`.
4. **Dual-Aspect Responsive Layout:** `GeometryOracle` with `STEP_ROOM_SPEC` passes at `1920x1080` and
   `2048x1536`; every toy is ≥120×120 and inside the canvas.
5. **Observability & Traceability:** `logs.sh audit --self-test` and `trace-stories.sh --strict` exit `0`.
6. **Bounded motion:** BOUNCE 1.1 s, SPIN 1.3 s, SQUEEZE 0.5 s; `is_idle()` is true only at rest, and a
   resting prop does not drift when advanced.
7. **Distinct interactions:** the scene tracks an interaction **set**, so a repeated toy never counts twice
   and the tickle zone never advances the step.
8. **Credit once:** PLAY is credited only when the loop is in PLAY, guarded by `credited`; a replay after
   the step finishes the room and credits nothing.
9. **Calm exit:** the HomeButton resets every toy and abandons an uncredited step; finishing requests the
   Casa once, the same way the bath does.
10. **No text:** no `Label` with play meaning; the prompt is art and PT-BR voice.

## 3. Frozen Contract
`game/scripts/components/garden_prop.gd` — `class_name GardenProp`, `extends Control`:

```gdscript
signal interacted(interaction: String)
enum Kind { BOUNCE, SPIN, SQUEEZE }
var kind: Kind = Kind.BOUNCE
var interaction: String = "ball"
func trigger() -> bool
func advance(delta: float) -> void
func is_idle() -> bool
func reset_prop() -> void
```

`game/scripts/scenes/jardim.gd` — `class_name GardenScene`, `extends Control`:

```gdscript
const PROPS: Array[Dictionary]        # kind + interaction id, wired at _ready
var fsm: Fsm; var played: Array[String]; var credited: bool; var tickles: int
func prop(index: int) -> GardenProp
```

**Wiring note (learned the hard way):** `kind` and `interaction` are assigned in `_ready`, because a
property set on a scripted node *before* it enters the tree is not serialised by `PackedScene.pack` — the
first build had all three toys reporting `ball`, and only one interaction ever counted.

`game/tools/build_jardim_scene.gd` generates `jardim.tscn` (14 nodes): background, rig, three props, the
tickle zone, home button, bubble, confetti.

## 4. Test Scenarios
