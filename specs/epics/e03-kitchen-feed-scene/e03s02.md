## 1. Story Goal
The game knows its 10 foods as typed data, and QuiQui opens her mouth when a position comes close. Criteria 3 and 4 have no new control or scene here; they are proven by e03s03.

## 2. Acceptance Criteria
1. **Strict Typing & Lint:** `gdlint game/ && gdformat --check game/` exits `0`, and the type gate passes.
2. **Explicit State Machine:** Any stateful behavior uses `Fsm` (`res://scripts/core/fsm.gd`) with zero `fsm.illegal_transition` or `fsm.dwell_timeout` events under `FsmProbe`.
3. **Touch & Mouse-Echo Safety:** Interactive controls filter `device == -1` synthesized mouse echo and act once when the echo is present.
4. **Dual-Aspect Responsive Layout:** `GeometryOracle` passes at both `1920x1080` (16:9) and `2048x1536` (4:3 iPad) with zero letterbox bars and `>=120x120 px` hit targets.
5. **Observability & Traceability:** `bash scripts/logs.sh audit --self-test` and `bash scripts/trace-stories.sh --strict` exit `0`.
6. **Catalog:** exactly 10 foods. Every id passes `Ids.is_valid`, every `art_path` exists under `res://assets/art/items/`, and every `.tres` loads as `ItemData`.
7. **Tray:** `pick_tray` returns `count` distinct items, and the same seed gives the same tray. `count` above 10 is clamped.
8. **Bad data degrades:** an unknown id returns `null`, and a missing art path returns a `null` texture and logs, without crashing.
9. **Anticipation:** `update_food_proximity` with a point strictly under 220 px from `mouth_global_center()` shows `boca_aberta`; at 220 px or more it does not. The change is immediate, on that call.
10. **Restore:** moving away, or `clear_food_proximity()`, restores the expression shown before anticipation (not always `base`, because QuiQui may be `carente`). Repeated calls while close do not re-emit `expression_changed`.
11. **Blink safety:** the blink never overwrites `boca_aberta`, and `reset()` clears anticipation.
12. **Zone inside the rig:** `mouth_zone` lies inside `get_visual_global_rect()` (TEST_PLAN §1.4).

## 3. Frozen Contract
`game/scripts/resources/item_data.gd` — `class_name ItemData`, `extends Resource`:

```gdscript
@export var id: String = ""
@export var art_path: String = ""
func texture() -> Texture2D      # null, with a log event, when the art is missing or the id is invalid
```

`game/resources/foods/<id>.tres` — one file per food. `game/scripts/core/food_catalog.gd` — `class_name FoodCatalog`:

```gdscript
const FOOD_IDS: Array[String] = ["cenoura", "macarrao_cenoura", "molho_cenoura", "cenoura_quiqui", "maca", "banana", "morango", "melancia", "uva", "cupcake"]
static func all() -> Array[ItemData]
static func get_item(id: String) -> ItemData     # null when unknown
static func pick_tray(rng: RandomNumberGenerator, count: int) -> Array[ItemData]  # distinct items
```

`game/scripts/components/quiqui_rig.gd` additions:

```gdscript
const MOUTH_ANTICIPATION_PX: float = 220.0
const ANTICIPATION_EXPRESSION: String = "boca_aberta"
func mouth_global_center() -> Vector2
func update_food_proximity(global_point: Vector2) -> void
func clear_food_proximity() -> void
```

The rig knows nothing about `TouchDraggable`; e03s03 connects them.
