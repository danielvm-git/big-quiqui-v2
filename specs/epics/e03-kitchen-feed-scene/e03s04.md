## 1. Story Goal
The whole FEED journey is locked by an end-to-end test, starting from the Casa door, using only input events and the real autoloads. A defect these tests expose is fixed in this story.

## 2. Acceptance Criteria
1. **Strict Typing & Lint:** `gdlint game/ && gdformat --check game/` exits `0`, and the type gate passes.
2. **Explicit State Machine:** Any stateful behavior uses `Fsm` (`res://scripts/core/fsm.gd`) with zero `fsm.illegal_transition` or `fsm.dwell_timeout` events under `FsmProbe`.
3. **Touch & Mouse-Echo Safety:** Interactive controls filter `device == -1` synthesized mouse echo and act once when the echo is present.
4. **Dual-Aspect Responsive Layout:** `GeometryOracle` passes at both `1920x1080` (16:9) and `2048x1536` (4:3 iPad) with zero letterbox bars and `>=120x120 px` hit targets.
5. **Observability & Traceability:** `bash scripts/logs.sh audit --self-test` and `bash scripts/trace-stories.sh --strict` exit `0`.
6. **Full journey:** Casa FEED door tap -> `cozinha.tscn` requested -> 3 drags to the mouth -> `bites == 3`, `CareLoopManager` in `BATH`, `completed_steps() == 1`, Casa requested exactly once. Passes at 1920x1080 and 2048x1536.
7. **Double drop:** replaying a drag's release (and the whole event list) on a consumed food changes nothing: `bites` rises once, one `nhami`, one `care.complete`.
8. **Miss:** a drop away from the mouth returns the food, with no bite and no care transition, and the same food can then be eaten.
9. **Two fingers:** a second touch on another food during a drag moves nothing.
10. **Second visit:** feeding again after FEED is done keeps the loop in `BATH`, with zero illegal transitions.
11. **Probes clean:** `FsmProbe` on `kitchen_feed` and `care_loop` reports no rejections or timeouts across the journey, and no diary line fails `logs.sh audit`.
12. **Flake check:** the full suite passes 3 times in a row.

## 3. Frozen Contract
`game/tests/integration/test_feed_e2e.gd`. Input goes only through `TouchSim.drag_events` and `TouchSim.gui_event`, with mouse echo on. No test calls a `KitchenScene` handler or sets `bites`, and no production API is added for a test.

## 4. Test Scenarios
SC-E03-P0-22 full journey, both aspects; SC-E03-P0-23 double-drop idempotency; SC-E03-P1-24 miss then eat; SC-E03-P1-25 second finger; SC-E03-P1-26 second visit.
