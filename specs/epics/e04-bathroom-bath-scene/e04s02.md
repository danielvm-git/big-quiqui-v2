# e04s02: BathScene Stage 1 (SOAP) — Sponge & Eight Foam Patches Inside the Hull

## 1. Story Goal
The bathroom exists and its first stage is playable: eight soap-foam patches sit on QuiQui, rubbing the
sponge soaks them one at a time, and the eighth closes the stage. Placement is solved from
`QuiQuiRig.scrub_hull_global()` on every layout pass, so a patch can never land on the wallpaper on 4:3 —
the failure the previous epics could not see.

## 2. Acceptance Criteria
1. **Strict Typing & Lint:** `gdlint game/ && gdformat --check game/` exits `0`, type gate passes.
2. **Explicit State Machine:** the stage machine is a `Fsm` (`SOAP -> SOAP_DONE -> RINSE -> DRY ->
   FINISHED`, declared now, used through e04s03) with zero illegal transitions under `FsmProbe`.
3. **Touch & Mouse-Echo Safety:** the sponge is a `TouchDraggable` in `CONTINUOUS_SCRUB` mode; the echo
   filter is unchanged; one press is one gesture.
4. **Dual-Aspect Responsive Layout:** `GeometryOracle` passes with `STEP_ROOM_SPEC` at `1920x1080` and
   `2048x1536`, and every one of the eight patches has its centre inside the hull on `1920x1080`,
   `1920x1440` and `2048x1536`.
5. **Observability & Traceability:** `bash scripts/logs.sh audit --self-test` and
   `bash scripts/trace-stories.sh --strict` exit `0`.
6. **Eight patches, one body:** `blob_count() == 8`, each blob's centre inside the hull, each at least
   24 px across, on two rings at 0.55 and 0.85 of the hull radius — a pattern on her body, not a grid.
7. **Soaking is exactly once:** a scrub point inside a patch soaks it and increments `soaked` once;
   a second point on the same patch does nothing; a point outside every patch does nothing.
8. **Stage closes once:** the eighth soak moves `SOAP -> SOAP_DONE`; the edge back to `SOAP` is illegal.
9. **Resize keeps them on her:** a canvas change mid-stage re-projects all eight patches inside the new
   hull (T-E04-07), keeping their ring/angle slot rather than re-randomising.
10. **Soap changes foam, never geometry:** tapping one of the three soaps recolours every patch; the
   patches stay inside the hull and the scene stays textless.
11. **No text:** `banheiro.tscn` carries no `Label` with text; prompt is art + PT-BR voice.

```gdscript

var is_soaked: bool = false
func contains_global_point(point: Vector2) -> bool
func soak() -> bool          # idempotent; true only on the transition
func reset_blob() -> void
```

`game/scripts/scenes/banheiro.gd` — `class_name BathScene`, `extends Control`:

```gdscript
const BLOB_COUNT: int = 8
const BLOB_RATIO: float = 0.11
const RING_FRACTIONS: Array[float] = [0.55, 0.85]
```

`game/tools/build_banheiro_scene.gd` generates `res://scenes/banheiro.tscn`: background, rig, 8 `Foam*`
nodes (group `foam`), `Sponge` (group `hit_target`), 3 `Soap*`, `HomeButton`, `WishBubble` (group
`wish_bubble`), `Gota`/`Bolhas` particles.
