## 1. Story Goal

A four-year-old does not tap politely. She mashes three fingers, drags off-target, taps during
fades, and taps the same door eleven times. This story proves that nothing in the game can be
put into a state the model forbids by a random, unsequenced, concurrent touch stream.

## 2. Acceptance Criteria

1. **Strict Typing & Lint:** `gdlint game/ && gdformat --check game/` exits `0`; CONVENTIONS §5
   bars respected (300 lines/file, 20 lines/function).
2. **Deterministic fuzz:** 1,000 events from a fixed seed reproduce the exact same sequence;
   the seed is printed on failure so any finding is reproducible from the log.
3. **No stall, no crash:** after the stream, no `Fsm` reports a dwell timeout it did not
   recover from, `SceneManager` is not stuck in a pending transition past its 2.0 s watchdog,
   and the save file still parses into a valid `SaveData`.
4. **No orphan blow-up:** the node count after the stream returns to (mount + declared
   transient) within one frame of quiescence; no node leaks per 100 events.
5. **Every event is filtered:** no control fires twice for one finger (the `device == -1`
   contract holds under concurrency, not only under `TouchSim.tap_control`).
6. **Observability & Traceability:** `bash scripts/logs.sh audit --self-test` and
   `bash scripts/trace-stories.sh --strict` exit `0`; the script carries `# story: e11s02`.

## 3. Frozen Contracts

### 3.1 The event stream is data
`MonkeyStream.events(seed, count)` returns `Array[InputEvent]`; the same seed yields the same
array. Position, finger index, press/move/release and echo flags come from the seeded RNG only.

### 3.2 Concurrency is bounded by the device
At most three touch indices are down at any moment (iPad toddler hand), and each index is
released before it is pressed again. A stream that violates this is a bug in the helper, not
in the game.

### 3.3 Quiescence is total
After the last event, `await` one idle frame plus the transition watchdog budget. The asserted
end state is: valid save, legal FSM state, zero `fsm.illegal_transition`, zero
`scene.watchdog`.
