## 1. Story Goal

Turn the fifteen cross-cutting invariants that produced BUG-001..BUG-054 into executable
gates, and walk the scene graph with a deterministic model-based test so a future epic cannot
regress one silently.

The existing 484 tests answer *"does this scene do what its story says?"*. They do not answer
*"can any code path, any tampered save, or any random tap reach a state the model forbids?"*.
Every historical bug lived in that gap: a save that could be tampered into a free party
(BUG-048), a wheel that paid the same prize forever (BUG-037), a per-*instance* guard that
looked per-session (BUG-039), a gate that could not fail (BUG-040), a diary event that was
never emitted on mount (BUG-046).

## 2. Acceptance Criteria

1. **Strict Typing & Lint:** `gdlint game/ && gdformat --check game/` exits `0`; every new
   file respects the CONVENTIONS §5 bars (300 lines/file, 20 lines/function).
2. **Invariant layer (INV):** `INV-01..INV-08` below are asserted by real tests, and each one
   is proven able to fail (C9).
3. **Model-based walk (MBT):** a seeded 500-step random walk over the scene graph asserts the
   FSM tables, the economy bounds and the save round-trip on every step, with a fixed seed so
   a failure reproduces exactly.
4. **No weakening:** no existing test, gate or workflow is deleted, skipped or relaxed to gain
   green. New files only, plus the preflight L1 count grows with them.
5. **Observability & Traceability:** `bash scripts/logs.sh audit --self-test` and
   `bash scripts/trace-stories.sh --strict` exit `0`; every new script carries
   `# story: e11s01`.

## 3. Frozen Contracts

### 3.1 `SaveData.from_dictionary` must be total
For **any** `Dictionary` input — including wrong types, negative numbers, absurd magnitudes,
nested junk, `null`-ish values, duplicate placement ids, unknown keys — the function returns a
`SaveData` that satisfies all of:

- `0 <= coins <= MAX_COINS`, `0 <= tickets <= MAX_TICKETS`, `0 <= completed_cycles <= MAX_CYCLES`
- every key and value in `equipped_outfits` passes `Ids.is_valid`
- every entry of `owned_furniture` passes `Ids.is_valid` and is unique
- every entry of `placed_furniture` has a valid `id`, unique, `0 <= x,y <= 1`
- **every placed id is owned** (a tampered save cannot place what she never bought)
- every `friend_stars` key passes `Ids.is_valid`, every value in `0..MAX_STARS`
- no key outside the eight declared fields survives

### 3.2 Round-trip idempotence
`from_dictionary(d.to_dictionary()).to_dictionary() == d.to_dictionary()` for every cleaned
`d`, and for every corpus entry: normalising twice equals normalising once.

### 3.3 A refused mutation is invisible
`buy_furniture`, `place_furniture`, `remove_furniture`, `equip` on a refusal path change
neither RAM (`to_dictionary()`) nor the bytes of the save file. A successful call writes
exactly once (`write_count` grows by 1).

### 3.4 Economy tables are total and non-degenerate
`EconomyData.furniture_prices` covers `FurnitureCatalog.FURNITURE_IDS` exactly (no missing, no
extra), every price ≥ 1, every wheel weight ≥ 1, every prize payout ≥ 1, and
`wheel_spin_ticket_cost ≥ 1`. A zero price is a free gift and therefore a defect, not a
default.

### 3.5 Diary vocabulary is closed and id-shaped
Every event id a script emits matches the auditor's `\A[a-z0-9_.]+\z` shape, is emitted at
least once from a real call site (no dead vocabulary), and no payload carries prose under
`msg`.

### 3.6 FSM tables are closed
For every declared machine: every edge target is itself a declared state or a documented
terminal, every state has a dwell entry or is terminal, and `transition_to` on an undeclared
edge emits `fsm.illegal_transition` and leaves `state` unchanged.

### 3.7 Scene contracts are machine-checked for every `.tscn`
Root type is a `Control` subclass, `anchors_preset = 15` (`PRESET_FULL_RECT`), each background
`TextureRect` uses `STRETCH_KEEP_ASPECT_COVERED`, no `Label`/`RichTextLabel` node carries text
(no reading required), and every `res://` path the scene or its script references resolves.

### 3.8 Every gate can fail
Each oracle/auditor is driven with a deliberately broken input and must report a finding:
`GeometryOracle`, `PlacementOracle`, the diary auditor, `trace-stories.sh --strict`.
