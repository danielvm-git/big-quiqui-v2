# e07s02: Playable Scene 8: CelebrationScene — confetti, PT-BR voice, atomic +5 coins / +1 ticket

- **Epic:** `e07-sleep-and-celebration-scenes`
- **BCP:** 4
- **Playable Vertical Target:** `res://scenes/quarto_sono.tscn` + `res://scenes/celebracao.tscn`
- **Threat findings closed here:** T-E07-03 (reward once per cycle), T-E07-04 (reward atomic with the counter)

## 1. Story Goal
The celebration: confetti burst, the family voice congratulates her, and the cycle pays
+5 coins / +1 ticket **exactly once**, atomically with the cycle counter, then back to the Casa.

## 2. Acceptance Criteria
1. **Strict Typing & Lint:** `gdlint game/ && gdformat --check game/` exits `0`, type gate passes.
2. **Touch & Mouse-Echo Safety:** every interactive node filters `device == -1`; one tap or drag is one action.
3. **Observability & Traceability:** `logs.sh audit --self-test` and `trace-stories.sh --strict` exit `0`.
1. Entering the scene plays the celebration voice and one confetti burst (not on a loop).
2. The reward is granted through `ProgressManager.complete_cycle` and is paid **once per cycle** — the `_rewarded_cycle_id` guard is asserted from the scene, not assumed.
3. Reward and `completed_cycles` increment happen in one `_apply`, then one save; a second entry in the same cycle pays nothing.
4. `complete_cycle` is called only when the loop is in `CELEBRATE`; coming back later is free play.
5. The Casa is requested exactly once; `HomeButton` leaves early without paying twice.
6. No text; `GeometryOracle` passes with `STEP_ROOM_SPEC` on both canvases.

## 3. Frozen Contract
`game/scripts/scenes/celebracao.gd` — `class_name CelebrationScene`, `extends Control`:

```gdscript
const COINS: int = 5
const TICKETS: int = 1
var credited_cycle: int = -1

```
`celebracao.tscn`: background (`bg_celebracao`), rig (`pulando`), `HomeButton`, `Confetti` particles;
voice `celebrate_parabens.ogg`, music `tema_principal.ogg`.
