## 1. Story Goal
The closet is playable: four outfits on the left rail, six accessories on the right, drag one onto
QuiQui with the `SNAP_TO_SLOT` gesture and she wears it — the hanger flies home, the wardrobe keeps its
contents, the look is saved and the next room opens already dressed. DRESS is credited once.

## 2. Acceptance Criteria
1. **Strict Typing & Lint:** `gdlint game/ && gdformat --check game/` exits `0`.
2. **Explicit State Machine:** `DRESSING -> FINISHED` on one `Fsm`; the loop's own machine is driven only
   through `CareLoopManager`.
3. **Touch & Mouse-Echo Safety:** every item is a `SNAP_TO_SLOT` `TouchDraggable`; one drag is one drop
   under the mouse echo.
4. **Dual-Aspect Responsive Layout:** `GeometryOracle` with `STEP_ROOM_SPEC` passes at `1920x1080` and
   `2048x1536`; items are ≥120×120 and inside the canvas.
5. **Observability & Traceability:** `logs.sh audit --self-test` and `trace-stories.sh --strict` exit `0`.
6. **The wardrobe:** `OUTFITS` (4) + `ACCESSORIES` (6), each item carrying `payload_slot`/`payload_id`,
   all wired by `_wire_items()`.
7. **Snap equips:** a drop on her body equips that slot, plays `pop_roupa` and bursts sparkles; the item
   returns home and its state is `REST`. A drop elsewhere changes nothing and plays no success sound.
8. **One per slot:** dropping a second hat replaces the first (T-E05-05); other slots untouched.
9. **Persistence:** the equip goes through `ProgressManager.equip`, so a new visit opens dressed —
   asserted by mounting the scene twice in one test.
10. **DRESS once (T-E05-02):** credited on the first successful equip when the loop is in DRESS; a second
    credit is refused by the loop; equipping when DRESS is not the step credits nothing.
11. **Leaving early:** the HomeButton abandons an uncredited DRESS step.
12. **No text:** the scene carries no `Label` with text; the prompt is art + PT-BR voice.

## 3. Frozen Contract
`TouchDraggable` gains the third mode:

```gdscript
signal snapped(slot: String, id: String)
var snap_target: Control = null
var snap_margin: float = 0.0
var payload_slot: String = ""
var payload_id: String = ""
```

`ClosetScene`:

```gdscript
const OUTFITS: Array[String]            # 4 ids, art under quiqui/
const ACCESSORIES: Array[Dictionary]    # 6 {slot, id}, art under items/
var fsm: Fsm; var credited: bool; var equips: int
func outfit_item(index: int) -> TouchDraggable
func accessory_item(index: int) -> TouchDraggable
```

`game/tools/build_closet_scene.gd` generates `closet.tscn` (27 nodes): background (`bg_quarto`), rig,
`Outfit0..3`, `Accessory0..5`, `HomeButton`, `WishBubble`, `Sparkles`.
