## Story Goal
Deliver `res://scenes/roda.tscn`: a single **SPIN** control with a **single-spin lock** `Fsm` (no queue, no double spend), **one ticket** deducted when the spin starts, and a **seeded** prize table so tests reproduce the same outcome. The scene is readable without text: wheel art + SFX/voice already in `assets/audio/voice/roda_boa_sorte.ogg`. Child returns home via the same `HomeButton` pattern as other step rooms.

**Why seeded:** determinism under `manual_step` matches `WishBubble` / `SceneManager` — property tests in e08s04 depend on it.

## Acceptance Criteria
1. **Strict typing & lint:** `gdlint game/ && gdformat --check game/` exits `0`.
2. **Explicit Fsm:** Wheel spin flow uses `Fsm` with declared `legal_edges` and `max_dwell_sec`; `FsmProbe` reports no `illegal_transition` / `dwell_timeout` in tests.
3. **Touch & mouse-echo:** `TapButton` / scene handlers filter `device == -1`; double-tap spin cannot deduct two tickets (idempotent lock through Fsm + tests).
4. **Dual-aspect layout:** `GeometryOracle` passes at `1920×1080` and `2048×1536`; spin `TapButton` ∈ `hit_target`, ≥120×120 px; background full-bleed (`background` group).
5. **Economy writes:** Ticket spend and coin prize go through `ProgressManager` (`add_tickets(-1)` pattern or dedicated `spend_ticket` if added — must clamp so tickets never negative). Coin prize via `add_coins(prize)`.
6. **FIX-05 — `EconomyData`:** New `class_name EconomyData` extends `Resource` with `@export var wheel_spin_ticket_cost: int = 1`, `@export var wheel_prize_weights: Dictionary` (prize_id → int weight), `@export var wheel_prize_coins: Dictionary` (prize_id → int coins). `WheelScene` loads defaults via `preload` or `load` of a `.tres` next to script; tests pass a custom instance for seeding.
7. **FIX-04 — badge:** A “NEW!” badge (Control + `TextureRect`, `MOUSE_FILTER_IGNORE`) sits above the spin button; visible when `tickets > 0` and the child has **never** completed a successful spin this session (`WheelScene` local flag); hidden after the first successful spin and stays hidden for the session.
8. **Observability:** Structured `Log` events for `wheel.spin_start`, `wheel.prize` (ids only), `wheel.badge_hide` as appropriate; `bash scripts/logs.sh audit --self-test` clean.
9. **Traceability:** `bash scripts/trace-stories.sh --strict` clean; every new script and test tagged `# story: e08s03`.
