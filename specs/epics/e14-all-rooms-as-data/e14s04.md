## 1. Story Goal

The two rooms D6 unblocked become scene data on the templates e13 already shipped. The wheel is one
pick on `t51_prize_pick`. The penguin is a catch game on `t50_lanes`. Neither template grows a room noun,
a second pick, an ad, a life or a fail state.

## 2. Requirements

#### ADDED: `wheel.tres` on `t51_prize_pick`
**After:** The prize set, the ticket cost and the coin payout are def parameters whose numbers come from `EconomyData` (the legacy wheel's prize table). One tap picks one prize. `ProgressManager` debits the ticket and credits the coins. A second tap in the same visit does nothing. There is no ad and no `AddVideoAdReward` branch. Voice key `vo.wheel.intro`.

#### ADDED: `penguin_lanes.tres` on `t50_lanes`
**After:** The def names the catch target, the spawn set and the seed. A catch scores. A miss leaves quietly and does not fail the round. The def copies no `ROUND_SEC` fail clock from `pinguim_jogo.gd`. The payout is the `pinguim` row of `EconomyData.minigame_coins`, once, plus one star. Spawned nodes despawn. The same seed and the same touch stream replay the same objects.

## 3. Acceptance Criteria

1. **Strict typing and lint:** fully annotated; lint and format pass; 300/20 bars hold. New scripts and tests start with `# story: e14s04`. No network API.
2. **The wheel is scene data on `t51_prize_pick`:** the template file gains no prize table and no wheel noun. Pay-once and the ticket debit stay in `ProgressManager`. Re-entry does not pay again.
3. **The penguin is scene data on `t50_lanes`:** no projectile, no life, no screen shake, and no def key that turns those on. Completion is the catch count in the def. Orphan node count is zero after a long run.
4. **The village and the party can open them:** `village.tres` gains destination `wheel`. `party.tres` friend door `pinguim` requests `penguin_lanes` through `SceneCatalog`. Both ids resolve to defs, not to `roda.tscn` or `pinguim_jogo.tscn`, when opened from the player.
5. **Legacy scenes remain:** `roda.tscn` and `pinguim_jogo.tscn` still exist. `find game/scenes -name '*.tscn'` returns 18. Both rooms lay out at `1920×1080` and `2048×1536`.
6. **Save stays atomic:** ticket and coin changes go through `ProgressManager`'s `.tmp` rename. Tests use `user://test_progress.json`.

## 4. Zoom-Out on the Modules This Touches

**`t51_prize_pick` and `t50_lanes`** — purpose: one pick, and catch-on-lanes, already built in e13.

- Callers: the player, via the template registry. This story adds defs, not a second implementation.
- Contracts to preserve: one pick, no ad (e13s09); catch only, seeded spawner, no loss (e13s08). A room noun inside either template file is a failure.

**`EconomyData`** — purpose: hold prize weights, ticket cost and minigame coins.

- Callers: legacy wheel and penguin, and now the two defs.
- Contracts to preserve: the numbers move into the def by reference to `EconomyData`. The story does not retune them.

## 5. Frozen Contracts

### Prizes and lanes are data

The template holds no table. The def does not invent a payout the economy resource does not already have.

### A miss is quiet

No life, no shake, no fail clock. This is the e13s08 contract applied to the penguin room. The legacy 20-second round is not copied, because that template has no fail state.

### D6 is already spent

These templates are wave 1b. This story does not wait for e15 or e16, and it does not move Steer or Spawner.
