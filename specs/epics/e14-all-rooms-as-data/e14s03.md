## 1. Story Goal

The rooms that are not the care day and not the two D6 games become data. Duck and album get the
library slots D5 named, because no TutoTOONS number fits them. Party is the seventeenth room
(`festa`). Its beat step uses `t22_play_beat` only when e13 shipped that template; a D3 skip is
recorded and no replacement beat is invented.

## 2. Requirements

#### ADDED: Six rooms as scene data
**After:** `market.tres` buys furniture through `t21_touch_each` plus the existing coin gate. `playhouse.tres` free-places owned furniture with `t45_dress_decorate`. `bear_puzzle.tres` is four `t20_drag_snap` slots. `duck_dance.tres` runs on the new slot `t_rhythm_pose`. `album.tres` runs on the new slot `t_album`. `party.tres` opens when five furniture pieces are placed, and its friend doors are scene ids.

#### ADDED: `t_rhythm_pose` and `t_album` as closed registry ids
**After:** Both ids sit in the template registry const map. The player loads them by id. Neither id is a filesystem path. `t_rhythm_pose` is the duck the game already has: three rounds, three pads (`left`, `centre`, `right`), a miss replays the same pose, nothing is lost, the win pays `EconomyData` once and grants one star. `t_album` shows friend cards and the stars already stored by `ProgressManager`. It writes no image file and opens no camera.

#### ADDED: Party follows the shipped `t22` or the D3 skip
**After:** When e13s07 shipped `t22_play_beat`, the dancing step names that template and supplies only parameters the evidence rule already accepts. When e13s06 or e13s07 skipped it, `party.tres` has no beat step, the skip is named in the def's note to the template table, and the friend doors stay on `t21_touch_each`. `t3_skip_beat` is not given a room. No shipped QuiQui room in the reuse map uses it.

## 3. Acceptance Criteria

1. **Strict typing and lint:** fully annotated; lint and format pass; 300/20 bars hold. New scripts and tests start with `# story: e14s03`. No `HTTPRequest`, `HTTPClient` or `WebSocketPeer`.
2. **Market keeps the price table:** a tap buys one shelf id from `FurnitureCatalog`. The price is `EconomyData.furniture_prices`. A short wallet plays the soft error and does not write the save. A owned piece stays owned. Voice key `vo.market.intro`.
3. **Playhouse stores ratios:** an owned piece lands where the child lets go, saved with `ProgressManager.place_furniture` as room ratios, never pixels. An unowned id is rejected before the save call. Placing the fifth piece is what the party lock reads (`PARTY_MIN_PLACED` is 5).
4. **Bear is four slots:** wrong drops return the piece. Settle pays the `urso` row of `EconomyData.minigame_coins` once and grants one star. No new prize amount is introduced.
5. **Duck and album do not grow new verbs:** three rounds, miss replays, no fail state, pay once. Album reads stars, returns by scene id `village`, and has no photo capture, no `PhotoGallery` verb and no file write of an image.
6. **Party does not invent a beat:** the def uses shipped `t22_play_beat` or the D3 skip, as above. Friend taps request `duck_dance`, `bear_puzzle` and, once e14s04 has written it, `penguin_lanes`, each through `SceneCatalog`. A locked party points at `playhouse` and does not scold. Voice key `vo.party.congrats` plays when the party is open.
7. **Village learns the new ids:** `village.tres` gains `market`, `playhouse`, `party` and `album` as catalog destinations. Legacy `.tscn` files stay. `find game/scenes -name '*.tscn'` returns 18. Playhouse ratios agree at `1920×1080` and `2048×1536`.

## 4. Zoom-Out on the Modules This Touches

**Template registry** — purpose: map a template id to one script.

- Callers: `SceneDef` validation and the player.
- Contracts to preserve: one id, one script, closed const map. `t_rhythm_pose` and `t_album` are new keys in that map. An unknown id is a validation failure.

**`ProgressManager` and `EconomyData`** — purpose: own purchases, placement, stars and minigame payouts.

- Callers: market, playhouse, bear, duck, album.
- Contracts to preserve: atomic `.tmp` rename; prices and payouts stay in `EconomyData`; the templates hold no price table.

## 5. Frozen Contracts

### No invented `t22` or `t3` behaviour

The party beat is the template e13 shipped, or it is absent because D3 skipped it. Silent evidence stays a def parameter only when e13s07 already put that parameter on the template. This story does not add one.

### Ids, not paths, and no photos

Friend doors and the album's return target are catalog ids. The album is stickers and stars. It is not the TutoTOONS photo gallery.

### Reason for depth

`t_rhythm_pose` and `t_album` exist so the library has one shape (D5) for the two screens that have no TutoTOONS number. They are not a new gesture family.
