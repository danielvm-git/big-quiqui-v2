## 1. Story Goal

Close the window D1 accepted. One commit deletes the 17 legacy scene scripts, the 17 scene builders
and the 17 generated `.tscn` files, and re-points the catalogs and the scene tests at ids in that
same commit. After it, the tree has one navigation mechanism.

## 2. Requirements

#### REMOVED: The 17 hand-built scenes
**Before:** `game/scenes/` holds `scene_player.tscn` plus 17 generated room scenes. Each room has a script in `game/scripts/scenes/` and a builder in `game/tools/build_*_scene.gd`. `SceneCatalog.ALL_PATHS` lists the 17 paths. `PoiTable` and `FriendCatalog` can still answer with a `res://scenes/*.tscn` path.
**After:** (removed) Those 17 scripts, 17 builders and 17 `.tscn` files are gone in one commit. `find game/scenes -name '*.tscn'` prints only `game/scenes/scene_player.tscn`. `scene_player.gd` and `build_scene_player_scene.gd` stay. The 17 `res://data/scenes/<id>.tres` files stay, including `kitchen.tres`.

#### MODIFIED: Catalogs and scene tests speak ids
**Before:** Navigation tests, the MBT walk, the monkey fuzz and the visual gallery iterate `SceneCatalog.ALL_PATHS` and instantiate a room `.tscn`.
**After:** They iterate the 17 scene ids and instantiate `scene_player.tscn` with that id's def (`ScenePlayer.def_override` or `SceneManager.request_def`). `PoiTable` maps POI to id. `FriendCatalog` maps friend to scene id. `SceneManager` compares `home` and `celebration`, not `casa.tscn` and `celebracao.tscn`. A def value that looks like a `res://` path is rejected and logged.

## 3. Acceptance Criteria

1. **One commit:** the deletions and the re-points land together. A checkout of the parent still has the 17 scenes. A checkout of this commit has one `.tscn`. No intermediate commit keeps mixed path-and-id navigation (D1a).
2. **The find gate:** `find game/scenes -name '*.tscn'` returns exactly `game/scenes/scene_player.tscn`. The 17 names are `album`, `banheiro`, `casa`, `casinha`, `celebracao`, `closet`, `cozinha`, `festa`, `jardim`, `mercado`, `pato_danca`, `pinguim_jogo`, `quarto_sono`, `roda`, `titulo`, `urso_puzzle` and `vila`.
3. **Scripts and builders match that list:** `game/scripts/scenes/<name>.gd` and `game/tools/build_<name>_scene.gd` are absent for each of those 17. `game/scripts/scenes/scene_player.gd` and `game/tools/build_scene_player_scene.gd` remain.
4. **Catalogs are id tables:** `SceneCatalog` exposes the 17 ids (`title`, `home`, `kitchen`, `bathroom`, `closet`, `playroom`, `bedroom`, `celebration`, `village`, `wheel`, `market`, `playhouse`, `party`, `duck_dance`, `bear_puzzle`, `penguin_lanes`, `album`). `PoiTable` and `FriendCatalog` do not return a legacy `.tscn` path. Every id loads a def.
5. **Tests move with the catalogs:** `test_scene_contracts.gd`, `test_scene_manager.gd`, `test_mbt_walk.gd`, `test_monkey_fuzz.gd` and `test_visual_gallery.gd` instantiate the player per id. The player root stays a `Control` at `PRESET_FULL_RECT`. Every new or changed file keeps the 300/20 bars, strict typing, and a `# story: e14s05` tag where this story touches it. Grandfathered files that this commit deletes (`banheiro.gd` at 326 lines) leave the allowance map in the same commit if the size gate requires it.
6. **The gate is green:** `bash scripts/preflight.sh` passes. `bash scripts/trace-stories.sh --strict` passes. Save writes remain atomic. No network API is added. `user://` progress is not hand-edited.
