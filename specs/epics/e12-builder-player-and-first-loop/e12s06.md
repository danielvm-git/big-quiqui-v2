## 3. Acceptance Criteria

1. **Strict Typing & Lint:** fully annotated; lint/format pass; template and def within the 300/20 bars.
2. **One template, no special cases:** `t20_drag_snap` implements the `single`/`slots` modes of the Give primitive plus `repeat: n`; it knows nothing about kitchens, food or QuiQui's name.
3. **The room is data:** `kitchen.tres` declares background, music, intro voice key, item ids, the receiver (`quiqui.mouth`), `repeat: 3`, and the on-hit/on-miss reactions. Changing the tray is a data edit.
4. **The loop answers every bite:** each feed plays the chewing pose, the chomp SFX, the crumb particles and the wish bubble's next item, in the same frame.
5. **FEED is credited once:** the third bite calls `CareLoopManager.complete_step(FEED)` exactly once and the room returns home; re-entering after FEED is free play that credits nothing.
6. **No timer, no punishment:** a missed drop returns the food to the tray with a soft sound; there is no deadline and no losing state.
7. **Slice Done, observed:** a pre-reading child feeds QuiQui three times with no adult help, in one sitting, and asks to play again. The observation is recorded in `specs/verifications/` with the date and what was seen.

## 4. Zoom-Out on the Modules This Touches

**`Template registry`** — purpose: map a template id from a def to the script that runs it, and reject an unknown id.

- Callers: `SceneDef` validation and the player's step runner.
- Contracts to preserve: One id, one implementation; an id absent from the registry is a validation failure, never a silent no-op.

**`CareLoopManager`** — purpose: own FEED→SLEEP and the cycle reward.

- Callers: Every care room, the celebration, the hub's door dimming.
- Contracts to preserve: The player calls `complete_step(FEED)` exactly once per visit; the loop, not the room, decides what comes next.

## 5. Frozen Contracts

### Template ↔ data boundary

The template reads only its `StepDef`. If it needs a value the def does not carry, the def grows — the template never hardcodes a Kitchen noun.

### The care loop stays above the player

The player reports a completed step; `CareLoopManager` owns the transition and the door dimming.

### Home is always available

The home button exits from every state; the step is credited only when earned.

## 9. Risks

- **The slice's Done is an observation, not a test.** If the loop is not delightful, the plan must change before e13 spends nine stories on more templates. Mitigation: the playtest step is last and its record is the gate.
- **`repeat: 3` and the care step can disagree** (three bites, two credited). Mitigation: one end-to-end test that counts `complete_step` calls.
- **Kitchen values leaking into the template** would make the next room a copy-paste. Mitigation: a source-scan test asserting the template file contains no Kitchen noun (the repo already has `source_scanner.gd`).
