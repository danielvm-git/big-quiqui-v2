# e12s01: English-First Ids and Voice-by-Key (the one-time rename)

## 1. Story Goal

Every asset, voice line and id in the tree becomes English snake_case, and voice becomes a key
(`vo.kitchen.intro`) instead of a file path, so the first scene written as data is written in the
vocabulary the game keeps. This is the largest mechanical diff of the wave and it lands first on
purpose (D2a): no id is ever written twice.

## 2. Requirements

#### RENAMED: Every asset id is English snake_case
**Before:** 100 art and 35 audio files were named in Portuguese (`kitchen.ogg`, `carrot.png`), and 208 references in 56 scripts plus 111 inside 17 generated `.tscn` files carried those names.
**After:** The same 135 files carry English ids from the design page's naming table (`kitchen`, `carrot`), with no Portuguese name left anywhere under `game/`. Behaviour is unchanged by construction; the diff is a rename.

#### ADDED: Voice is addressed by key
**After:** `vo.<scene>.<line>` resolves through `AudioManager` to `assets/audio/voice/pt_BR/<locale>/<line>.ogg`, default locale `pt_BR`. An unknown key logs `audio.missing_key` and returns `false`; it never crashes and never locks input.

## 3. Acceptance Criteria

1. **Strict Typing & Lint:** `gdlint game/ && gdformat --check game/` exits `0`; CONVENTIONS §5 bars respected.
2. **One vocabulary:** no file under `game/assets/art/` or `game/assets/audio/` has a Portuguese name; the naming table in `QUIQUI_BUILDER_DESIGN.html` (Today | New id) is the authority for every rename.
3. **Nothing lost:** the 135 asset files each keep a matching `.import` sidecar, Godot re-imports clean, and no `.import` or `.uid` file is hand-edited.
4. **Both trees stay bootable:** the 17 legacy `.tscn` files are regenerated from their builders (never hand-edited) and every one loads with zero missing-resource errors.
5. **Voice by key, with its own grammar (F-1):** `AudioManager` resolves `vo.<scene>[.<line>]` to
   `assets/audio/voice/pt_BR/<locale>/<line>.ogg`. The key grammar is **its own** (`\Avo\.[a-z0-9_]{1,32}(\.[a-z0-9_]{1,32}){0,2}\z`), not `Ids.PATTERN` — a dotted key is not an id. The path is assembled from segments that already passed the check, never from a split of raw input; the locale defaults to `pt_BR`, and a rejected or missing key logs `audio.missing_key` and swaps nothing instead of crashing or locking input (`SC-e12s01-P0-01`).
6. **Grammar:** every id still matches `\A[a-z0-9_]{1,64}\z` (`Ids.PATTERN`) and every art path the game loads still matches the `res://assets/art/...` shape the code already enforces.
7. **Observability & Traceability:** `bash scripts/logs.sh audit --self-test` and `bash scripts/trace-stories.sh --strict` exit `0`; the story's files carry `# story: e12s01`.

## 4. Zoom-Out on the Modules This Touches

**`AudioManager`** — purpose: own the music/SFX/voice channels, the crossfade and the -9 dB ducking.

- Callers: `game/scripts/scenes/*.gd` (17) today pass a `res://` path straight to `play_voice`/`play_music`; the new player will pass keys.
- Contracts to preserve: `play_voice(stream)` keeps its signature; the resolver is additive (`play_voice_key`), the bus layout and ducking stay byte-identical, and `reset()` keeps clearing every channel.

**`game/tools/build_*_scene.gd`** — purpose: author each generated `.tscn` so nobody hand-edits a scene file.

- Callers: Run by hand; the committed `.tscn` is their output and is never edited directly (CONVENTIONS §Never).
- Contracts to preserve: `SceneBuilder.pin`/`pack_and_save` keep their signatures; each builder still writes exactly one scene; the 17 outputs must still load with zero missing resources.

## 5. Frozen Contracts

### The rename is mechanical

One pass renames files and updates references. A behaviour change smuggled into this diff is unreviewable and therefore rejected.

### Keys are stable, files are not

Code, data and tests reference `vo.kitchen.intro`. Only the resolver knows that today it is a PT-BR recording.

### No compatibility aliases

There is no `cozinha` fallback path. A leftover Portuguese reference is a failing test, not a fallback.

## 8. Out of Scope

- Re-recording any voice line (the family recordings are renamed, never replaced).
- New art, including the ghost hand (flagged in scope as the one known gap).
- Translating parent-area text (TranslationServer work waits for a second locale).

## 9. Risks

- **Rename churn hides a behaviour change.** Mitigation: the only code change allowed in this story is the resolver; every other edit is a string, and the full suite must be green at both ends of the diff.
- **`.import` sidecars, not the `.png`, carry the resource path.** A `git mv` without the sidecar re-imports under a new UID and leaves a stale entry. Mitigation: move file and sidecar together, then `godot --import` and check the suite.
- **A missed reference fails at runtime, not at compile time** (a `res://` string). Mitigation: the id-grammar test plus a scene-loads-clean test over all 17 scenes, both written before the rename.
- **The design page's table does not name every file.** Mitigation: step 1 produces the complete map first; unnamed files get a name derived from the same scheme and are listed in the map for review.
