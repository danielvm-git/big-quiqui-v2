## Defects found

1. **Test gap, M6:** remembering the face again while food stays close saves `boca_aberta` as the face to restore, so the mouth stays open. No test covered it. Added `test_repeated_calls_while_close_keep_the_face_to_restore`.
2. **Test gap, M4:** the reset test could not see stale memory, whose real effect is that the next approach does not open the mouth. The test now makes that approach.
3. **Design gap closed before implementation:** a naive remember would restore `pisca` if food arrives mid-blink, and the blink timer only reopens a face still showing `pisca`. The rig remembers `base` in that case.

The "zone inside visual rect" criterion passed on real layouts with no rig layout change, so no defect was recorded there.
