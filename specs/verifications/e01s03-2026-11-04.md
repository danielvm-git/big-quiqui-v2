## Behaviour proven (SC-E01-P1-04/05/06)

- **Round-trip survives a RAM reset**: coins, tickets, cycles, outfits, furniture,
  placements (normalized 0..1) and friend stars all return identical after
  `save()` → data dropped → `load_or_default()`.
- **Atomic write leaves no `.tmp`**: after `save()` the temp file is gone and the
  real file exists.
- **An orphan `.tmp` can never become the save**: a partially written temp file left
  by a simulated crash is ignored; the intact save wins.
- **Corrupt save recovers to defaults** with `last_error == "corrupt"` and no engine
  error — parsing now goes through `JSON.new().parse()`, which reports instead of
  pushing.
- **Untrusted input is sanitized**: negative coins clamp to 0, tickets clamp to the
  cap, friend stars clamp to 5, non-`String` ids are dropped (a numeric `42` would
  otherwise stringify into a plausible id), uppercase/invalid ids are dropped,
  placement coordinates clamp into 0..1.
- **Test mode never touches production**: `set_test_mode(true)` moves every read/write
  to `user://test_progress.json`; the production file's existence is unchanged.
- **`TestReset` wiring**: `reset_all()` now really reaches `ProgressManager` and calls
  `set_test_mode(true)`.

## Defects found and fixed here

1. **Typed-array assignment is strict in Godot 4.7** — `pm.data.owned_furniture = ["a"]`
   is a runtime error, not an implicit conversion. Test fixtures must use
   `var x: Array[String] = [...]`. Worth knowing before e02 writes save code.
2. **`type_gate` could not compile `class_name` scripts at all.** A fresh `GDScript`
   copy collides with the registered global class; stripping the declaration breaks
   `-> SelfName` return types; renaming breaks self-references. Final implementation
   loads the **real** script and `reload()`s it (verified: `load()` survives a parse
   error and returns the broken script, so the loop keeps counting).
3. **A numeric id in a JSON array stringified into a valid id** (`42` → `"42"`).
   `SaveData` now requires `String` before pattern-matching.
4. **`JSON.parse_string` pushed an engine error on corrupt input**, which GUT counts as
   a failure. Switched to `JSON.new().parse()` + `get_error()`.
