## The story

The e01 `titulo.gd` guard flipped live when e02s03 created `casa.tscn`. This story closes the loop and makes navigation **real in the shipped game**:

- `SceneManager` gained `set_test_mode(enabled)` (TestReset calls it on every manager), a `production_swap` injection seam, and `production_swap_path`.
- `_load_pending_or_current()` now branches: injected `loader` (tests) → `loader.call`; else if **not** test mode → `_swap_production(path)` → `get_tree().change_scene_to_file(path)` (with `scene.swap_failed` logging on error); in test mode the swap is suppressed while `scene_changed` still flows.
- `test_titulo_scene.gd`'s "casa does not exist yet" premise was retired honestly: the tap now asserts a real `scene_requested("res://scenes/casa.tscn")` with the stage staying mounted under GUT.
