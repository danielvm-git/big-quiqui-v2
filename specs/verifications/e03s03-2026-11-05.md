## Defects found

1. **Cancelled touch consumed a food.** `TouchDraggable` treated a cancelled touch as a release. It now goes to `RETURNING`.
2. **Double tap queued a reload.** `SceneManager.request_scene` rejected a repeat path only when idle, so a second tap on the FEED door parked the same scene and loaded it twice. A repeat is now rejected as `same_scene` in every state, and a parked different scene is left alone. Not added to `specs/bugs/registry.yaml`, by instruction.
3. **Kitchen theme would follow the child into the hub.** Casa now restores `main_theme.ogg` on arrival when it is not already playing, through the new `AudioManager.is_music_playing`.
4. **Dead guard.** Mutation testing showed that the check at the top of `_on_home_tapped` changed nothing, so it was removed.

## Deviations recorded

- **`seed_value` default is 0 instead of 20261105.** A fixed default would serve the same tray on every visit. 0 now randomizes on entry. The contract line in `e03s03.md` is updated.
- **One commit instead of develop-tdd's two-commit rule.** Requested by the brief. Red evidence is the table above.
- **Extra public members beyond the contract:** `tray`, `rig`, `bubble`, `crumbs` and `hearts`. Tests read them, and `tray` is how a test names the served foods.
- **`MAX_DWELL_SEC` is declared but `check_dwell` is not called.** The 0.9 s reaction timers use the same stepped clock, so a state cannot outlive the deadline while `advance` runs.
- **Reaction length (0.9 s each) is not in the spec.** It was chosen to stay well under the 2.0 s deadline. It should be judged in the windowed run.
- **T-E03-05 not applied.** The worktree guard refuses commands that set `HOME`, so test runs shared the default `user://`. The 3 runs were green, but another worktree testing at the same moment could interfere.
- **Bigpowers scripts absent from this repository:** `verify-adversarial.sh`, `check-blind-spots.sh`, `completeness-critic.sh`, `bp-churn-rank.sh`. Mutation testing and `git log` were used instead. `specs/verifications/e03s03-verify.yaml` was not written, because the brief names this report as the evidence.
- **Not proven headless:** real GUI dispatch and how the particles and tray look. The AC 15 run covered both, except motion.
