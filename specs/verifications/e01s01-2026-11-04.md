## Deviations recorded

1. **`TouchSim` proves the contract on events + handlers, not on window dispatch.**
   Godot's headless viewport does not deliver `push_input` to `_gui_input` (probed with a
   plain mouse press: nothing arrives). Window-level dispatch is covered by the on-device
   UAT of the first playable scene (e01s05).
2. **`Fsm` logging is lazy, not direct.** The FSM resolves the `Log` autoload at first
   event, so a unit test needs no autoload while the game still gets JSONL telemetry.
3. **`type_gate` renames `class_name` in its compile copy.** Re-declaring a registered
   global class is a collision, not a defect; renaming the declaration and its
   self-references keeps every real type error intact.

## Fresh-clone proof (added after the first epic-branch CI run)

`rm -rf game/.godot && bash scripts/preflight.sh` → **GREEN**, 29/29 tests.

The first CI run on the epic branch failed at the type gate with
`Could not find base class "GutTest"` even though L1 imported the project: the type
gate runs *before* GUT, and `class_name` resolution needs
`game/.godot/global_script_class_cache.cfg`, which is gitignored. Preflight now imports
the project once (stage `L0a`) before any stage that resolves global classes. This is
the same root cause as the earlier "GUT silently runs nothing" defect, fixed at the
right level instead of twice.
